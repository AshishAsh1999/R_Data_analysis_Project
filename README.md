# Tourism Accommodation Data Analysis in R (Quarto)

This repository contains an end-to-end data analysis project built using R and Quarto, applied to Irish tourism accommodation data from the ITM05 dataset. The project demonstrates how raw tourism data can be cleaned, structured, and explored to identify seasonal patterns and differences across accommodation types.

The analysis focuses on preparing categorical and numerical variables correctly, performing exploratory data analysis, and presenting insights through reproducible reporting.

## Project Objectives

The main objectives of this project are to clean and prepare raw tourism accommodation data, manage categorical variables such as month and accommodation type, perform exploratory data analysis, examine seasonal trends, compare patterns across accommodation categories, and present the analysis in a reproducible Quarto report.

## Repository Contents

The repository includes the Quarto source file containing the full analysis, a rendered PDF report, and the dataset used in the project. The dataset is stored in a dedicated data folder along with a brief dataset description.

## Dataset Description

The analysis is based on the ITM05 Tourism Accommodation Dataset, which contains monthly tourism accommodation statistics for Ireland. The dataset includes both categorical variables, such as month and main accommodation type, and numerical variables that measure tourism activity. This structure makes the dataset suitable for data cleaning, grouped analysis, and exploratory statistical summaries.

## Analysis Approach

The project begins with importing the raw dataset into R and preparing it for analysis by converting relevant variables into appropriate data types. Categorical variables are treated as factors, while numerical variables are validated to ensure they are suitable for statistical analysis.

Exploratory data analysis is then carried out to understand distributions, variability, and trends in the data. Summary statistics and visualisations are used to examine tourism patterns over time and across accommodation types. Particular attention is given to identifying seasonal effects and differences between categories.

The findings are compiled into a professionally rendered PDF report using Quarto, ensuring that the analysis is fully reproducible.

## Reproducibility

The analysis is designed to be reproducible using the provided Quarto file and dataset. All data paths are relative to the repository structure, allowing the report to be re-rendered in a new environment with minimal setup.

## Skills Demonstrated

This project demonstrates R programming, data cleaning and preprocessing, handling of categorical and numerical variables, exploratory data analysis, grouped and comparative analysis, data visualisation, and reproducible reporting using Quarto.

## Notes

The dataset is included for educational and analytical purposes. Minor adjustments to file paths or package versions may be required depending on the execution environment.
