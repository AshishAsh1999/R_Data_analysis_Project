# ITM05 Tourism Accommodation Dataset

## Dataset Overview
This dataset contains monthly statistics related to **tourism accommodation in Ireland**.  
It is commonly used for analysing visitor activity, accommodation usage, and seasonal patterns in the Irish tourism sector.

The dataset includes both **categorical** and **numerical** variables, making it suitable for data cleaning, exploratory data analysis, and grouped statistical summaries.

---

## Structure of the Dataset
Each row represents observations for a specific:
- Month
- Accommodation category

Key variable types include:

### Categorical Variables
- **Month**  
  Represents the month of observation.

- **Main Accommodation Type**  
  Categorises the type of accommodation (for example: hotels, guesthouses, self-catering, etc.).

### Numerical Variables
- Visitor-related measures (such as counts or totals associated with tourism activity).
- Other quantitative indicators used to analyse patterns and variation across time and accommodation types.

---

## Intended Use
This dataset is used in this project to:
- Practise data cleaning and preprocessing in R
- Convert and manage categorical variables
- Perform exploratory data analysis (EDA)
- Compare tourism patterns across accommodation types
- Investigate seasonal trends across months

---

## Notes
- The dataset is provided in CSV format.
- Month and accommodation variables are treated as categorical factors during analysis.
- Numerical variables are analysed using summary statistics and visualisation techniques.

---

## Source
This dataset is derived from Irish tourism accommodation statistics and is used here strictly for **educational and analytical purposes**.
